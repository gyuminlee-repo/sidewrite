# Preferences

## 항목

| 항목                     | 값                                                    | 호스트      |
| ------------------------ | ----------------------------------------------------- | ----------- |
| Track changes            | `Always (recommended)`, `Modifications only`, `Never` | Word        |
| Show diagnostics in chat | 켬 / 끔. 기본 끔                                      | Word, Excel |

### Track changes

- `Always`: 모든 편집을 추적된 변경으로 넣는다. 기본값이고 모든 편집을 검토할 수 있다.
- `Modifications only`: 여러 문단의 새 초안은 추적 없이 넣고 제자리 편집은 추적한다.
- `Never`: 추적하지 않는다.

채팅의 쓰기 도구는 모두 이 설정을 따른다.

### Show diagnostics in chat

세션, 도구, 턴 이벤트를 채팅에 보여 준다. 기본은 꺼짐이다. 턴이 멈추거나 도구 호출이 실패한 이유를 찾을 때 켜 두고 채팅에 남는 이벤트 줄을 읽는다.
